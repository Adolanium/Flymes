# Flymes Desktop

## Platform and stack

Windows Hermes Desktop. Plain ESM with host React and the verified Desktop SDK. The user delegated implementation choices.

## Purpose

Developers observe and control a connectome-derived supervisory policy beside the Hermes conversation. The simulator selects macro-actions; Hermes supplies language understanding and bounded execution.

## Constraints

The user requested a compact neural laboratory, host theme and typography, readable recording labels, explicit LIVE or REPLAY state, real telemetry, reversible lesions, and immediate stale or disconnected feedback. Missing measurements remain missing. A schematic rendering sample must never imply anatomical coordinates or full simulation coverage.
