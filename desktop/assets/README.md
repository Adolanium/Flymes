# Fly specimen

The specimen is an archived decorative dorsal illustration of Drosophila melanogaster.
It does not show anatomical neuron coordinates or live movement. Measured neural
samples remain in the separate schematic graph.

The PNG and WebP record the previous static treatment and are no longer shipped
in the panel. The panel now renders the articulated canvas fly from
`desktop/fly-avatar.js`. Run `node desktop/embed-avatar.mjs` after changing that
source to update the self-contained native plugin. Building the harness also
performs this step.
